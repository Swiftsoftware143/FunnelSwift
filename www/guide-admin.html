Admin Guide — System Tags & Auto-Provisioning

What Are System Tags?

System Tags are special tags that, when assigned to a lead, automatically trigger an action in another Swift app — like creating a free ADASwift account, adding a contact to CoreSwift CRM, or registering a lead in WorkflowSwift.

They're different from regular tags. Regular tags just organize your leads. System Tags do something when applied.

How It Works

  1. Lead gets tagged — A lead in FunnelSwift receives a System Tag (manually or via automation)
  2. Webhook fires — FunnelSwift sends a webhook to the target app with the lead's contact info
  3. App provisions — The target app creates a free account/contact for that lead
  4. No duplicates — If the email already exists, nothing happens

Creating a System Tag

Go to Super Admin > Tags > System Tags. Click + New Tag and fill in:

Managing Tags

From the System Tags table you can:

  • Toggle ON/OFF — Disable a tag without deleting it. While disabled, no webhooks fire.
  • Delete — Remove the tag entirely. Won't affect leads already tagged.

FAQ

Q: Can a lead upgrade themselves?
No. Free-tier accounts can only be upgraded by an admin.

Q: What if the webhook fails?
The tag still records in FunnelSwift but the target app won't create the account. Re-assign the tag to retry.

Q: What happens if I tag a lead that already exists?
The webhook detects the duplicate email and returns success without creating a duplicate.
